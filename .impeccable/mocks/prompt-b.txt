Use case: ui-mockup.
Create a polished, high-fidelity native Windows game-launcher concept for The Order: 1886. This is composition B, a dedicated launch panel. Render a single complete desktop app window, straight-on, landscape 3:2, crisp and readable, without surrounding desktop or concept-board labels.

Input image is a reference for the game's imagery, charcoal/brass/ivory identity, and serif wordmark. Preserve that recognizable identity while substantially redesigning the layout and readability. Retain the armored protagonist and misty Victorian London street in the artwork. This is an operating app interface, not a poster.

Structure: a slim native dark Windows title bar. Below it, the left 40 percent is an opaque charcoal operating panel; the right 60 percent is uninterrupted cinematic artwork with a careful crop that keeps the protagonist and street visible. The left panel has the brass serif wordmark "THE ORDER" / "1886" at its top. Immediately below, show "Game files found" as a restrained status, then a well-spaced "Game folder" field with "…\CUSA00076" and a "Change" button.

Use clear, aligned native form controls for "Display" set to "Borderless", "Upscaling" set to "FSR 1", and "Frame rate" set to "30 FPS". Each label has its own readable field, with generous separation between groups. Put the authentic warning "Experimental runtime. Gameplay is not yet verified." above a large, full-width matte brass "Play" button near the bottom of the panel. Under the button, secondary text actions "Settings", "Verify files", and "View logs" share a quiet footer. Keep the main action dramatically more prominent than these secondary tools.

Visual grammar: charcoal #0b0b0a, brass #d4bd75, ivory #e9e5d8, warm muted text #a8a497. Serif only for the elegant wordmark; use a highly readable Windows humanist sans for controls and body. Precise alignment, comfortable padding, native rectangular controls with subtly softened corners, thin quiet separators, strong contrast. Avoid ornamental frames and visual noise. The panel must feel intentional and premium rather than like the old list of menu commands.

Settings values are illustrative configuration, not performance readings. Show no CPU/GPU charts, measured FPS, benchmark claims, account, store, downloads, mod manager, or unsupported graphics features. Do not imply gameplay verification. No eyebrow labels above headings, section numbering, nested cards, pill-heavy UI, decorative glass/blur, extra emblems or unrelated branding. This layout should remain credible as a real Tkinter/Windows application.
