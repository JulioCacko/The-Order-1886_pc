## The 19 October sweep, in one paragraph

Two issues are closed with evidence ([#9](https://github.com/JulioCacko/The-Order-1886_pc/issues/9) updates, [#18](https://github.com/JulioCacko/The-Order-1886_pc/issues/18) Steam). Four advanced in source: [#8](https://github.com/JulioCacko/The-Order-1886_pc/issues/8) now catalogues every string the Go UI shows (249 still render in English), [#20](https://github.com/JulioCacko/The-Order-1886_pc/issues/20) made the in-game menu reachable behind an off-by-default setting and its live cap effective, [#14](https://github.com/JulioCacko/The-Order-1886_pc/issues/14) separated the presentation cap from game timing, and [#5](https://github.com/JulioCacko/The-Order-1886_pc/issues/5) turned the image-limit decision into one tested function that names its classification. [#2](https://github.com/JulioCacko/The-Order-1886_pc/issues/2) gained a page that states which resolution is which. [#15](https://github.com/JulioCacko/The-Order-1886_pc/issues/15) gained a version-bound patch catalogue that never writes the game folder, [#16](https://github.com/JulioCacko/The-Order-1886_pc/issues/16) exposes the two effects the renderer actually honours, [#14](https://github.com/JulioCacko/The-Order-1886_pc/issues/14) now shows the resolved timing on the Performance page, and the updater has a written durability contract with torn-write tests. A trace summariser turns a performance recording into percentiles without ever pronouncing an acceptance. Rounds 12–20 added a hardening pass against upstream shadPS4 and against the game's own import table — image shapes, allocations, packets, page faults, sampler fields, index bounds, stencil sizing, eight missing guest calls, fp64 opcode coverage, four GnmDriver stubs and subgroup memory barriers — recorded fix by fix with its test and its limits in [the runtime hardening note](verification/2026-10-20-runtime-hardening.md). None of that is gameplay acceptance. Everything else still needs the game build, vendor hardware or gameplay capture, and says so below.
