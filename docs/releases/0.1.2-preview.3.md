# The Order: 1886 - Windows launcher preview 0.1.2 (preview.3)

Download **order1886-windows.zip**, extract the complete folder, and open
**The Order 1886.exe**. Python, MSYS2 and a compiler are not required for the
portable package. Use your own extracted CUSA00076 game files. Keep your existing
`user/order1886` folder when upgrading; it contains your settings and saves.

## Changes

- New launcher profiles default to the original cinematic aspect and 30 FPS.
  Explicit saved choices are preserved; 16:9 and 60 FPS remain experimental options.
- Fix resource-free shader specialization so fullscreen clears retain the correct
  user-data offset, addressing a donor-reproduced flat-scene rendering defect.
- Correct legacy shader multiply-add and clamped log/reciprocal instructions,
  including zero, infinity and NaN handling.
- Prefer static vertex input on Intel to work around the donor's black-character
  driver issue. `ORDER1886_VERTEX_INPUT_DYNAMIC_STATE=0/1` permits diagnosis.
- Cache compute-pipeline binaries alongside graphics pipelines, with ordinary
  compilation as the fallback when binaries are unavailable or rejected.
- Invalidate older compiled shader artifacts automatically through the shader
  binary version. Existing saves are unaffected.
- Improve source graphics-probe evidence for aspect recipes, frame traces and
  captured output dimensions.

## Verification and limits

The Windows native build and 13 CPU checks passed. The full Python suite passed
192 tests with 28 skipped. RTX 3070 Vulkan smoke checks passed for graphics and
compute binary caching. The portable package is checked independently after building.

This remains an experimental compatibility preview. The invalid 8,029-layer image
crash (#5), Intel gameplay visuals, Chapter 6/9 QTE timing, sustained 4K/60 and
long-session stability remain unverified or unresolved. Passing launcher, preparation
and pipeline-cache checks does not establish gameplay acceptance.

Imported fixes are attributed in
[the donor reuse report](../order1886-donor-reuse.md), with
[detailed source verification](../verification/2026-10-17-donor-reuse.md).

## Portugues (Brasil)

Baixe **order1886-windows.zip**, extraia a pasta completa e abra
**The Order 1886.exe**. O pacote nao exige Python, MSYS2 ou compilador. Use seus
proprios arquivos extraidos do jogo CUSA00076. Preserve a pasta `user/order1886`
ao atualizar para manter configuracoes e saves.

Novos perfis usam o aspecto cinematografico original e 30 FPS; escolhas salvas
continuam valendo. Esta versao corrige especializacao e matematica de shaders,
aplica uma alternativa de entrada de vertices para Intel e adiciona cache binario
de pipelines compute. O cache de shaders antigo e invalidado automaticamente.

O erro de imagem com 8.029 camadas (#5), a imagem em gameplay no Intel, os QTEs
dos capitulos 6/9, 4K/60 sustentado e a estabilidade prolongada ainda precisam de
correcao ou validacao. Os testes de launcher, preparacao e cache nao comprovam
gameplay completo. Consulte **QUICKSTART.txt** para instalacao e uso.
