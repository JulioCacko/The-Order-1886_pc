# The Order: 1886 — Windows launcher preview 0.1.0

**Download `order1886-windows.zip` below to use the launcher.** The automatically
generated “Source code” archives are for developers. Python, MSYS2 and a compiler
are not required for the portable ZIP.

This is an **experimental preview**: boot and later 3D cinematics have been
observed. Interactive gameplay, checkpoint progression, a complete campaign and
sustained 4K/60 FPS remain unverified. The known Vulkan image-layer assertion
(`layers=8029/2048`) is not fixed by this release.

## Included

![Five-page Windows launcher](https://raw.githubusercontent.com/JulioCacko/The-Order-1886_pc/v0.1.0-preview.1/docs/images/order1886-desktop.png)

- Portable Windows x64 launcher and its dedicated native compatibility runtime.
- Five pages: Home, Graphics, Performance, Game and Advanced.
- Official game logos/emblem supplied by the user, the selected wallpaper,
  graphics settings, save backup/restore tools and session logs.
- **`QUICKSTART.txt` inside the ZIP**, with English and Brazilian Portuguese
  instructions for installation, your game folder, settings, saves and support.
- Runtime identity, file manifest, GPL license and dependency notices.

**No game executable, game archives, firmware or player saves are included.**
Bring your own extracted PS4 **CUSA00076** copy. This is an unofficial community
project; image and trademark rights remain with their respective owners.

## Start here

1. Download **`order1886-windows.zip`** and extract it completely to a writable
   folder. Keep `The Order 1886.exe`, `bin` and `_internal` together.
2. Open **`QUICKSTART.txt`**, then **`The Order 1886.exe`**.
3. Choose the game folder directly containing `eboot.bin`, `archivemap.bin`,
   `_data`, `sce_sys/param.sfo` and `sce_module` with `libc.prx`/`libSceFios2.prx`.
4. For your first attempt, use **30 FPS** and **Original cinematic aspect**.
   Save settings and press **Play**. Advanced contains the session logs.
5. Use **Stop session** to close the runtime. Preserve the entire `user` folder
   when updating so your settings, saves and backups remain available.

Requires 64-bit Windows 10/11 and a Vulkan-capable GPU with a current driver.
60 FPS/16:9 are experimental; the timing patch warns of QTE softlocks in
Chapters 6 and 9. Selected settings do not guarantee measured performance.

## Verification and support

The launcher/backend regression suite and source GUI checks passed locally.
The ZIP passed all **9 relocated portable smoke checks**, archive CRC checks
and verification that the bilingual manual is included. Those checks cover
packaging and startup, not gameplay acceptance.
Use the attached **`.sha256`** file to verify the ZIP.

For a problem report, include the matching `last-run.json`, boot/session log,
runtime SHA256, game version, GPU/driver, settings and reproduction steps.
Review logs for personal paths before sharing; do not upload game files or saves.

## Português (Brasil)

Baixe **`order1886-windows.zip`**, extraia tudo e leia **`QUICKSTART.txt`**.
Nao precisa de Python ou compilador. Abra **The Order 1886.exe**, escolha seu
dump extraido **CUSA00076**, comece com **30 FPS** e **Original cinematic aspect**,
grave as opcoes e clique **Play**. Mantenha `bin` e `_internal` junto do EXE.

O pacote nao inclui jogo, firmware ou saves. E uma previa experimental: ha
cinematicas 3D observadas, mas gameplay, checkpoints e desempenho sustentado
ainda exigem validacao. O erro Vulkan `layers=8029/2048` continua sem correcao.
Guarde a pasta `user` inteira antes de atualizar. O manual bilingue inclui
estrutura do dump, backups, logs e instrucoes de suporte.
