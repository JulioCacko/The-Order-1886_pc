# The Order: 1886 — Windows launcher preview 0.1.0 (preview.2)

**Download order1886-windows.zip below to use the launcher.** The automatically
generated “Source code” archives are for developers. Python, MSYS2 and a compiler
are not required for the portable ZIP.

This is an experimental update. It improves SRT fault handling, walker reuse and
mapped-range lookups, and makes the existing image-descriptor diagnostics
available through the source launcher. The reported Vulkan assertion requesting
8029 image layers when the device limit is 2048 remains unresolved. This release
does not certify interactive gameplay, checkpoint progression, sustained 4K/60
FPS or long-session stability.

## Changes

- Recoverable speculative resource-table faults no longer permanently patch a
  shared SRT walker.
- Identical generated and loaded SRT walkers reuse code with byte-checked
  matching; a patched walker invalidates the cache.
- Vulkan mapped-range lookups use per-thread snapshots refreshed after map and
  unmap changes, with rasterizer identity checks.
- Setting ORDER1886_DIAG_RESOURCE_SHARPS=1 before starting the source launcher
  forwards the existing raw image-descriptor diagnostics to the runtime.
- Existing format-aware Vulkan upload bounds checks now have an explicit
  regression check.

## Included

- Portable Windows x64 launcher and its dedicated native compatibility runtime.
- Five pages: Home, Graphics, Performance, Game and Advanced.
- User-supplied logos/emblem, graphics settings, save backup/restore and session logs.
- QUICKSTART.txt with English and Brazilian Portuguese instructions.
- Runtime identity, file manifest, GPL license and dependency notices.

**No game executable, game archives, firmware or player saves are included.**
Bring your own extracted PS4 CUSA00076 copy. This is an unofficial community
project; image and trademark rights remain with their respective owners.

## Start here

1. Download order1886-windows.zip and extract it completely to a writable
   folder. Keep The Order 1886.exe, bin and _internal together.
2. Open QUICKSTART.txt, then The Order 1886.exe.
3. Choose the game folder directly containing eboot.bin, archivemap.bin,
   _data, sce_sys/param.sfo and sce_module with libc.prx/libSceFios2.prx.
4. Start with 30 FPS and Original cinematic aspect. Save settings and press Play.
5. Use Stop session to close the runtime. Preserve the entire user folder when
   updating so settings, saves and backups remain available.

Requires 64-bit Windows 10/11 and a Vulkan-capable GPU with a current driver.
60 FPS and 16:9 remain experimental; the timing patch warns of QTE softlocks in
Chapters 6 and 9. The selected settings do not guarantee measured performance.

## Verification and support

The hosted Windows package workflow passed the native runtime build and CPU
checks, all 77 Order-specific Python regressions, and all 9 relocated portable
smoke checks. The downloaded ZIP matches its SHA-256 sidecar and passes archive
CRC validation. The portable smoke checks cover packaging and startup, not
gameplay. The local Python suite also ran 189 tests with 28 skipped. None of
these checks reproduces the post-prison crash or establishes gameplay
performance.

Use the attached .sha256 file to verify the ZIP. For a problem report, include
the matching last-run.json, boot/session log, runtime SHA256, game version,
GPU/driver, settings and reproduction steps. Review logs for personal paths
before sharing; do not upload game files or saves.
