## The Order: 1886 — v0.2.2 (launcher hotfix)

A launcher-only hotfix on top of [v0.2.1](https://github.com/JulioCacko/The-Order-1886_pc/releases/tag/v0.2.1). The runtime is unchanged.

### Import decrypted PS4 saves

**Import saves…** (Game & Content → Saves) now accepts the folder layout that decrypted PS4 saves come in, such as the output of Apollo Save Tool: `<id>_CUSA00035_Playthrough00` folders holding the save's files and `sce_sys\param.sfo`. In v0.2.1 this layout was refused.

Choose the folder that holds those save folders (for example `CUSA00035`) or one save folder. The launcher converts each save into the layout the runtime reads: the save's files, plus its title, subtitle and icon taken from `param.sfo`. Your current saves are backed up first and only saves with the same name are replaced. Then start the game and choose Continue or Load.

Still refused, with a message that says why: encrypted saves copied straight off a PS4 (a save image next to a `.bin` key file), and saves of another game.

The bundled QUICKSTART.txt now explains save import.

### Unchanged

The runtime and its known issue: short black flashes still appear during gameplay, and their cause has not been found yet.
