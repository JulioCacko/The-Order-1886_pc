## The Order: 1886 — v0.2.3

Builds on [v0.2.2](https://github.com/JulioCacko/The-Order-1886_pc/releases/tag/v0.2.2). From [#115](https://github.com/JulioCacko/The-Order-1886_pc/pull/115), which fixes [#113](https://github.com/JulioCacko/The-Order-1886_pc/issues/113).

### 60 FPS and 16:9 with update 1.02

Before this release, a game with update 1.02 applied could only start at 30 FPS with the original framing. 60 FPS, 90 FPS, Unlocked, 16:9 and turning a post effect off were all refused:

> Experimental 60 FPS metadata mismatch for APP_VER: expected 01.00, found 01.02.

The executable was never the problem. Update 1.02 ships the same `eboot.bin` that these options were built and tested on. Only the version numbers in `param.sfo` differ.

Each of these options now checks the game's own code at every place it changes, not a file hash or a version number. A game with or without update 1.02 works. A build whose code differs is refused, and the message names the address.

Measured on the base game with update 1.02 laid over it, at 60 FPS and 16:9 (RTX 3070): 59.3 FPS from the intro to the title screen, and the picture fills the whole 16:9 frame.

### Every edition of the game

The launcher now accepts all six editions of The Order: 1886, in any folder:

| Edition | Status |
| --- | --- |
| CUSA00076 | tested |
| CUSA00035, CUSA00070, CUSA00100, CUSA00670, CUSA00785 | experimental: no real dump of these was available, so please report how they run |

All six share the same saves. Trophies are kept per edition. Brazilian Portuguese voices and text exist only in CUSA00785. On CUSA00035, CUSA00070 and CUSA00076 the game uses Portugal Portuguese, where it previously fell back to English.

### Save import

- A decrypted save export with no title ID in its `param.sfo` is now refused, like another game's save.
- A folder holding both runtime saves and decrypted exports now imports both. Before, the exports were skipped.

### Unchanged

60 FPS and above are still experimental. The published 60 FPS patch warns of QTE softlocks in Chapters 6 and 9. Short black flashes still appear during gameplay, and their cause has not been found yet.
