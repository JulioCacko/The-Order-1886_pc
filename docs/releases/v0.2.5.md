### Native 4K, with no upscaler (#3)

Graphics → **Render resolution** makes the game itself draw a larger frame. Choose Original (1920 wide), 2560, 3840 or a custom width: a multiple of 16 from 1280 to 4880, or up to 4192 with 16:9 framing. At 3840 the game renders 3840×1600 (letterboxed into 3840×2160), or the full 3840×2160 with 16:9 framing. Every screen-sized pass runs at that size, and the frame reaches the screen 1:1.

- At any size other than Original, upscaling is set aside and the image is presented as drawn.
- The game's executable is patched only in the prepared copy, and every site is byte-checked first. Your game files are not changed.
- The render-target memory and the guest memory grow with the size automatically.
- Measured on an RTX 3070 at 3840×1600 in 30 FPS mode: 30 FPS in the street and on the Chapter I rooftop, with drops to 27 FPS in the Chapter II Council cutscene. This release's package held 30 FPS on a night rooftop loaded from a save. 60 FPS at 4K is not reached. Shadow maps and MSAA still use their original sizes. Update 1.02 only for now; base 1.00 follows. Evidence: [native resolution verification](https://github.com/JulioCacko/The-Order-1886_pc/blob/main/docs/verification/2026-10-29-native-resolution.md).

### Borderless stays borderless (#121)

On Windows, Borderless and Windowed could be taken into exclusive full-screen by the driver, so Borderless behaved like Fullscreen. Both now ask the driver not to. Switching display mode from the in-game menu recreates the swapchain. With G-Sync set to "full screen only", G-Sync does not engage in Borderless; set it to "full screen and windowed mode".

### Linux: mixed-case game folders (#124)

On ext4 and btrfs, a dump whose folders differ in case from the names the game asks for (for example `ps4/GPU/`) crashed at boot. The runtime now matches each missing path component without case, as the PS4 and Windows do.
