## The Order: 1886 — v0.2.7

Builds on [v0.2.6](https://github.com/JulioCacko/The-Order-1886_pc/releases/tag/v0.2.6) and adds the button prompts from [#135](https://github.com/JulioCacko/The-Order-1886_pc/pull/135). If you are on v0.2.5 or earlier, this release also carries every v0.2.6 fix.

### Xbox and keyboard button prompts (#135)

Controls → **Button prompts** chooses the buttons the game draws in prompts, menus, quick-time events, stealth takedowns and Lycan evades:

- **PlayStation (original):** the game's own artwork.
- **Xbox:** A, B, X, Y, LB, RB, LT, RT, LS, RS, Menu and View. Each original texture is kept; only its PlayStation marking is replaced by the matching letter, in the original's own ink and softness.
- **Keyboard and mouse:** keycaps, mouse buttons and a WASD cluster. Choosing it also applies the matching key layout (Space vault, C cover, R reload, E interact, Q Blacksight, Shift sprint, mouse aim and fire), so the prompts show keys that act. It replaces any custom keyboard buttons.

The first launch with Xbox or Keyboard and mouse builds the prompts from your own game files: a few seconds for Xbox, about a minute for keyboard. The result is cached under your player data and mounted like a mod, after any enabled mods. Your game files are not changed, and the release ships only this project's own artwork. Guide: [Button prompts](https://github.com/JulioCacko/The-Order-1886_pc/blob/main/docs/order1886-button-prompts.md).

### From v0.2.6

- **Launcher (#131):** Open installation, logs and player data open their folders; Check for updates says **Up to date** on the latest release; downloads show progress and can't be started twice.
- **Runtime executable (#127):** a wrong pick is refused when you choose it, with the reason; **Use installation runtime** clears it. A closed game window is named as the reason a session ended.
- **GPU-library stops, exit 23 (#133):** invalid shader pointers read zero as on the PS4, and seven crash fixes come from SpartanPort, including the command-buffer reuse that stopped a 4K run here with "Unimplemented PM4 type 0". Not confirmed against the reporter's crash.
- **CPU use (#134):** audio threads above normal, GPU waits that back off, and a per-thread CPU report in the boot log. No measured drop in total CPU use yet.
- **Linux:** the package builds again after a warning in the #134 code stopped it.

Details: [v0.2.6 release notes](https://github.com/JulioCacko/The-Order-1886_pc/releases/tag/v0.2.6).

### Unchanged

60 FPS and above are still experimental, and the published 60 FPS patch warns of QTE softlocks in Chapters 6 and 9. Render sizes other than Original, and turning post effects off, remain experimental. The launcher window on SteamOS still needs WebKitGTK 4.1.
