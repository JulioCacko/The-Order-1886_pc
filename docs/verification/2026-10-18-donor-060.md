## Reproduced defects and adaptations

- The original translator fails an unordered comparison with a NaN operand.
  `out/order1886-evidence/gold-work/donor-060/shader-math-red.log` records the
  assertion. The corrected translator handles NaN in either operand, ordered
  and unordered F32/F64 comparisons, inactive CMPX lanes, constant true CMPX,
  and legacy reciprocal-square-root signed zero. Existing legacy multiply and
  clamped math regressions remain in the same production-translator fixture.
- The original graphics key assignment fails equality/hash consistency when its
  destination storage contains nonzero bytes (`out/pipeline-key-red.log`).
  Copy construction and assignment now preserve the bytes included by the
  existing comparison and hash, including self-assignment.
- Float atomic fallback expressions previously selected two already-executed
  mutations. The adapted backend emits an exclusive pair of branches with one
  atomic per arm and a result phi. The generated-code regression checks buffer
  and image min/max, sign-bit routing, both predecessor labels, and four
  consecutive splits. It does not execute game shaders or establish shadow
  quality.
- NaN math regressions inspect and evaluate production SPIR-V expressions for
  saturation in F32/F64 and trinary min/max/median, including each NaN position
  and both trinary-extension capability settings. Saturation still assumes
  DX10_CLAMP; preserving NaN when that bit is disabled requires shader control
  propagation.
- Unpacked ELF imports and same-second save retention had failing synthetic
  regressions before the changes. All 35 focused Python tests pass: prepare 14,
  backups 10, libc linking 9, module linking 2. ELF parsing retains architecture,
  program-header bounds, payload limits and truncated-input rejection. Backup
  ordering is numeric and suffix allocation remains increasing after pruning.
  Concurrent backup writers remain outside the existing contract.
