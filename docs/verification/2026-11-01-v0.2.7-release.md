## Button prompts from the package

- The `65f54e1` package (before the CFG fix) died building Xbox prompts: exit 127, no message.
  A frozen probe built with the same PyInstaller options showed an access violation in Unicorn's
  `Uc.mem_map`; the same probe with `GUARD_CF` cleared built all 98 bitmaps. `python.exe` has no
  CFG, which is why source builds worked.
- With the fix, the packaged backend (`order1886-worker.exe --run-backend --button-prompts …`)
  built Xbox (98 bitmaps at `520b5d8`, 131 at `8b628d9` with the coverage plan) and keyboard (151
  at `520b5d8`) prompts on CUSA00076 without a crash. In the `520b5d8` package, Chapter Selection
  read "Ⓐ SELECT Ⓑ BACK".
- The README screenshots of the prompts in game (`docs/images/v0.2.7/prompts-*.jpg`) come from
  the coverage session's runs from source with the same plan; the Controls screenshots are the
  packaged v0.2.7 launcher's window client area.
