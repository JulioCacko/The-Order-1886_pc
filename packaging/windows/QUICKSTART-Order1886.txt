THE ORDER: 1886 FOR PC - QUICK START
Quick start / Guia rapido

ENGLISH
-------

WHAT THIS DOWNLOAD INCLUDES

The Order 1886.exe (the launcher), Play The Order 1886.exe (direct play), the
dedicated compatibility runtime and its libraries in bin, and license notices.
You do not need Python, MSYS2 or a compiler. This is unofficial,
emulator-backed compatibility software, not an official PC port.

No game executable, game archives, firmware or player saves are included.
Use your own extracted PS4 copy of The Order: 1886, in any edition:
CUSA00076 (tested), CUSA00035, CUSA00070, CUSA00100, CUSA00670 or CUSA00785
(experimental: report how they run). Update 1.02 may be applied or not.

BEFORE STARTING

- 64-bit Windows 10 or 11 and a Vulkan-capable GPU with a current driver.
  NVIDIA DLAA needs a GeForce RTX GPU. Performance varies by hardware.
- Extract the complete ZIP to a writable folder, for example
  C:\Games\The Order 1886\
  Do not run the EXE from inside the ZIP. Keep both EXEs and bin together.
- GitHub's "Source code" archives are for developers; download
  order1886-go-windows.zip.

YOUR GAME FOLDER

Choose the folder that directly contains these items, not its parent:

  CUSA00076\   (any folder name)
    eboot.bin
    archivemap.bin
    _data\
    sce_sys\
      param.sfo
    sce_module\
      libc.prx
      libSceFios2.prx

Keep the complete extracted game folder, including files not shown above.
Encrypted PKG files and an eboot.bin copied by itself are not sufficient.
The original files are only read; a separate working copy is prepared.

FIRST SESSION

1. Open The Order 1886.exe.
2. On Game & Content, choose your game folder.
3. On Performance, start with 30 FPS (60 FPS is also offered).
4. On Graphics, choose a display mode and upscaling: FSR 1, AMD FSR 3.1 or,
   on GeForce RTX, NVIDIA DLAA.
5. Press Play. The first start prepares the game and compiles shaders, which
   takes a while; later starts are faster.
6. Quit from the game window or with Stop. Do not interrupt a save.

LAUNCHER PAGES

Home: Play, the launch configuration and the game installation check.
Graphics: display mode, framing, upscaling, VSync, output resolution,
  sharpening, anisotropy and the four post effects.
Performance: 30/60/90 FPS and Unlocked, presentation cap, in-game menu and
  overlay items.
Controls: mouse camera, sensitivity, inverted Y and keyboard bindings.
Game & Content: game folder, game language, patches, saves, mods, desktop
  shortcut and Add to Steam.
Achievements: earned trophies. With your own console trophy key, trophy names
  and descriptions are decrypted from your game.
System: runtime override, performance recording, launcher language, updates,
  logs and cache tools.

Valid edits save automatically. Escape returns Home. Leave the runtime
override empty to use the bundled runtime.

IN THE GAME

Mouse: left = R2/fire, right = L2/aim. WASD moves, the mouse or arrows turn
the camera, I/J/K/L are the d-pad (rebind on Controls). Esc releases the
cursor; F6 captures or releases it. F9 toggles the performance overlay,
Insert opens the in-game settings menu and F12 saves a screenshot of the game.

SAVES AND UPDATES

Settings, prepared files, caches, logs and saves are kept in
  <launcher folder>\user\order1886\
Saves use the folder CUSA00035 from the game's metadata; do not rename it.
A backup is made before each session. On Game & Content, select a backup and
press Play to restore it before launch, then choose Continue/Load in the game.

To bring saves in, use Game & Content > Import saves... and choose a decrypted
PS4 save export (Apollo Save Tool: <id>_CUSA00035_<name> folders with
sce_sys\param.sfo), another installation's savedata folder or a save backup.
Current saves are backed up first. Encrypted saves copied straight off a PS4
must be decrypted first. Open saves folder shows where they are kept.

System > Updates checks GitHub releases and installs a verified package; the
previous version can be restored. To update by hand, close everything, extract
the new ZIP to a new folder and copy your user folder beside the new EXE.

WHAT IS NOT VERIFIED YET

Gameplay has been tested in parts of the campaign, not all of it. Full
progression, long sessions and sustained 4K/60 are not verified. 60 FPS,
90 FPS and Unlocked are experimental: the 60 FPS patch warns of possible QTE
softlocks in Chapters 6 and 9. If timing looks wrong, return to 30 FPS.

TROUBLESHOOTING

- Game files need attention: select the folder directly containing
  eboot.bin and check the structure above.
- Runtime or DLL missing: extract the whole ZIP again and keep bin.
- Black screen, crash or freeze: System > Open logs. Keep the matching
  session log and last-run.json.
- First-time effects can be missing for a moment while their shaders compile
  in the background. Turn off Async shaders on Performance to wait instead.

REPORTING A PROBLEM

Include last-run.json, the session log, the game version, GPU and driver,
your settings and the steps to reproduce. Remove personal paths from logs.
Do not upload game files or saves.

PORTUGUES (BRASIL)
==================

Este ZIP contem o launcher (The Order 1886.exe), o inicio direto (Play The
Order 1886.exe), o runtime de compatibilidade com suas bibliotecas em bin e as
licencas. Nao precisa de Python, MSYS2 ou compilador. E software de
compatibilidade nao oficial, baseado em emulacao; nao e um port oficial.
Nao inclui jogo, firmware ou saves. Use sua propria copia PS4 extraida de
The Order: 1886, em qualquer edicao (CUSA00076 testada; CUSA00035,
CUSA00070, CUSA00100, CUSA00670 e CUSA00785 experimentais).

COMO INICIAR

1. Baixe order1886-go-windows.zip em Releases, nao os arquivos "Source code".
2. Extraia o ZIP inteiro para uma pasta com permissao de escrita. Nao abra o
   EXE dentro do ZIP. Mantenha os dois EXEs e a pasta bin juntos.
3. Abra The Order 1886.exe. Em Game & Content, escolha a pasta que contem
   diretamente eboot.bin, archivemap.bin, _data, sce_sys e sce_module.
   Um PKG criptografado ou apenas o eboot.bin nao sao suficientes.
4. Em Performance, comece com 30 FPS. Em Graphics, escolha o modo de tela e o
   upscaling: FSR 1, AMD FSR 3.1 ou, em GeForce RTX, NVIDIA DLAA.
5. Clique Play. A primeira vez prepara o jogo e compila shaders e demora mais.

NO JOGO

Mouse esquerdo = R2/tiro, direito = L2/mira, WASD = movimento, mouse ou setas
= camera, I/J/K/L = direcional (altere em Controls). Esc libera o cursor e F6
captura/libera. F9 mostra o overlay, Insert abre o menu de opcoes no jogo e
F12 salva uma captura do jogo.

DADOS E ATUALIZACOES

Configuracao, saves, backups, caches e logs ficam em user\order1886 ao lado
do launcher. Os saves usam a pasta CUSA00035; nao a renomeie. Um backup e
feito antes de cada sessao. Em Game & Content, escolha um backup e clique Play
para restaura-lo antes de iniciar; depois use Continue/Load no jogo.
Para trazer saves, use Game & Content > Import saves... e escolha um export
de save PS4 descriptografado (Apollo Save Tool: pastas <id>_CUSA00035_<nome>
com sce_sys\param.sfo), a pasta savedata de outra instalacao ou um backup.
Saves criptografados copiados direto do PS4 precisam ser descriptografados antes.

System > Updates procura versoes no GitHub e instala um pacote verificado; a
versao anterior pode ser restaurada. Para atualizar manualmente, extraia o novo
ZIP em outra pasta e copie a pasta user antiga para junto do novo EXE.

AINDA NAO VERIFICADO

O jogo foi testado em partes da campanha, nao inteira. Progressao completa,
sessoes longas e 4K/60 sustentado nao foram verificados. 60 FPS, 90 FPS e
Unlocked sao experimentais; o patch de 60 FPS alerta para possiveis
travamentos em QTEs dos capitulos 6 e 9. Se o tempo parecer errado, volte
para 30 FPS.

Para relatar um problema, abra System > Open logs e envie last-run.json, o log
da sessao, a versao do jogo, GPU/driver, opcoes e passos para reproduzir.
Remova caminhos pessoais. Nao envie arquivos do jogo nem saves.
