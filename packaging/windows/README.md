# The Order: 1886 Windows preview

Use the current Order documentation:

- [Source build, dependencies and verification](../../docs/order1886-build.md)
- [Portable launcher usage and current limitations](README-Order1886.txt)
- [Runtime evidence and remaining acceptance gates](../../docs/order1886-runtime-status.md)

The portable package is produced by `order1886-go-build.ps1`. It contains no game
content and requires the player's existing extracted CUSA00076 directory.
Build and launcher checks do not establish menu, gameplay, stability or performance.

Historical setup instructions remain recoverable in repository history.
